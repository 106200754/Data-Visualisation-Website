Beyond Road Deaths

This COS30045 project examines hospitalised injuries from road crashes in Australia between 2011 and 2021.

Project purpose

The planned visualisation will explain how hospitalised road-crash injuries changed over time and identify important differences between road-user and age groups. The target audience is the Australian general public and road-safety policymakers.

Initial questions
1. How did the national total change from 2011 to 2021?
2. Which road-user groups changed the most?
3. Which age groups experienced the largest changes?
4. What limitations must users consider when comparing raw counts?

Data

The datasets were published through the Australian Government National Road Safety Data Hub and use hospital data sourced from the Australian Institute of Health and Welfare National Hospital Morbidity Database.

Files collected:
- National hospitalised injuries dataset
- State and territory hospitalised injuries dataset
- First Nations hospitalised injuries dataset
- Hospitalised injury data dictionary
Current progress

- Initial annual, road-user and age-group summaries calculated
- KNIME workflow in progress
- Website wireframe and D3 prototype planned for the next stage

Data limitation

The supplied tables mainly report absolute counts. Counts are affected by population size and should not be treated as direct measures of risk.
